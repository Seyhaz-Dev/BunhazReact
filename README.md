## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/Seyhaz-Dev/BunhazReact.git
```

### 2. Navigate to Project

```bash
cd BunhazReact
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
